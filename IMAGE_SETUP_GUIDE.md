## 📸 Add Your Images (3 Easy Steps)

### Step 1: Download Flower Images

**Quick Download Options:**

#### Option A: Free Stock Photos (Recommended)
1. Go to **Pexels**: https://www.pexels.com
2. Search for each flower:
   - "marigold flowers"
   - "jasmine flowers white"
   - "lotus flower pink"
   - "red hibiscus flower"
   - "red rose flowers"
3. Download high-quality images (free, no attribution required)

#### Option B: Unsplash
1. Go to: https://unsplash.com
2. Search same terms as above
3. Download free images

#### Option C: Your Own Photos
- Take photos of fresh flowers from your local market
- Use good lighting
- Square crop for best results

### Step 2: Prepare Images

1. **Rename** downloaded images to:
   - `marigold.jpg`
   - `jasmine.jpg`
   - `lotus.jpg`
   - `hibiscus.jpg`
   - `rose.jpg`

2. **Resize** (optional but recommended):
   - Size: 800x800 pixels (square)
   - Keep file size under 500KB
   - Use any image editor or online tool

### Step 3: Add to Project

1. Create folder if it doesn't exist:
   ```
   C:\Flora\public\images\
   ```

2. **Copy** all 5 images into:
   ```
   C:\Flora\public\images\
   ```

3. **Refresh** your browser (Ctrl + F5)

✅ **Done!** Images will appear in the slider automatically!

## 🔧 Troubleshooting

### Images not showing?

1. **Check file names** - Must match exactly:
   - `marigold.jpg` (not Marigold.jpg or marigold.png)
   
2. **Check file location**:
   ```
   C:\Flora\public\images\marigold.jpg
   ```

3. **Clear browser cache**:
   - Press `Ctrl + Shift + R` (Windows)
   - Or `Ctrl + F5`

4. **Check console** for errors:
   - Press `F12` → Console tab
   - Look for 404 errors

### Slider not auto-playing?

- It auto-starts when page loads
- Changes every 3 seconds
- You can manually navigate with ← → buttons
